Case Study Summaries
1. Tuple-Based Transaction Audit
Processes transaction records containing an ID, amount, and transaction
type. It identifies duplicate IDs, invalid amounts or types, and
suspicious consecutive transactions.
2. Student Group Formation with Score Balancing
Sorts student scores in descending order, divides them into groups of a
specified size, calculates group totals, and compares the totals. The
simple grouping method does not guarantee optimal balance.
3. Smart Canteen Order and Stock Management
Processes customer orders, checks item indexes and quantities,
calculates bills, updates available stock, rejects unavailable orders,
and reports total sales and remaining stock.
4. Library Borrowing and Fine Reconciliation
Calculates fines at Rs. 5 per delayed day, identifies overdue books,
counts borrowed books, and calculates the number of available books.
5. Campus Transport Allocation
Calculates the number of buses required for each route based on
passenger demand and bus capacity. It also identifies passengers who
cannot be served by the available buses.
6. Manufacturing Quality Control Matrix
Calculates defect percentages for production batches and identifies
batches exceeding the 5% defect threshold. It also calculates the total
number of defective units.
7. Nested List Examination Seating Validation
Checks an examination seating matrix for duplicate roll numbers, empty
seats, invalid roll numbers, and incorrect reserved-seat allocations. In
the matrix, 0 represents an empty seat and -1 represents a reserved
seat.
8. Water Distribution Fairness Analysis
Compares daily water supply with area-wise demand, calculates total
shortages, and identifies the most underserved area.
9. Multi-Product Price Fluctuation Analysis
Calculates the percentage change between the first and last recorded
prices of products. It flags products whose absolute price change
exceeds 10% and identifies the maximum fluctuation.
10. Tuple-Based Course Registration Validation
Checks student course-registration tuples for duplicate registrations
and prohibited combinations. A student cannot register for the same
course twice or register for both AI and ML.
How to Run
1. Install Python 3 on your computer.
2. Save the required case-study program in a file with the .py
   extension.
3. Open a terminal or command prompt in the folder containing the file.
4. Run the program using:
python filename.py
Replace filename.py with the name of the Python file you want to
execute.
